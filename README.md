# Consulta CNPJ

Página única (HTML, CSS e JS puro, sem dependências) que consulta um CNPJ em duas APIs públicas, BrasilAPI e CNPJ.ws, e junta as informações num só painel.

## Como usar

Abra `index.html` no navegador, ou acesse a versão publicada no GitHub Pages. Para consultar direto pela URL, use `?cnpj=<14 dígitos>`.
