# Consulta CNPJ

Página única (HTML, CSS e JS puro, sem dependências) que consulta um CNPJ em duas APIs públicas, BrasilAPI e CNPJ.ws, e junta as informações num só painel.

## Como usar

Acesse **https://douglascardoso99k.github.io/consulta-cnpj/** ou abra `index.html` no navegador. Para consultar direto pela URL, use `?cnpj=<14 dígitos>`.
